# Kirana Sign Interpreter - Vocabulary Register

The project uses exactly 10 grocery labels.

| Label | Kannada |
|---|---|
| rice | ಅಕ್ಕಿ |
| milk | ಹಾಲು |
| sugar | ಸಕ್ಕರೆ |
| salt | ಉಪ್ಪು |
| oil | ಎಣ್ಣೆ |
| dal | ಬೇಳೆ |
| wheat | ಗೋಧಿ |
| tea | ಚಹಾ |
| coffee | ಕಾಫಿ |
| biscuit | ಬಿಸ್ಕತ್ತು |

The authoritative starting reference is the Government of India's
Indian Sign Language Research and Training Centre (ISLRTC).

Website: https://divyangjan.depwd.gov.in/islrtc/

Individual sign verification is pending until the exact dictionary
entry and video have been reviewed.

Do not assume that an English dictionary entry automatically
proves that the corresponding grocery sign has been verified.

For each label, record:
- Exact dictionary term
- Exact video/reference URL
- Sign variant
- Static or dynamic classification
- Reviewer
- Verification status

Never invent an ISL gesture.
Never label an unverified gesture as an official ISL sign.
