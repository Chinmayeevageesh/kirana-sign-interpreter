# Official sources checked for this project

- Indian Sign Language Dictionary, ISLRTC / Government of India: https://divyangjan.depwd.gov.in/islrtc/
- ISLRTC FAQ: https://islrtc.nic.in/faq/
- ISLRTC dictionary information: https://islrtc.nic.in/isl-dictionary/
- Open Government Data catalogue: https://data.gov.in/catalog/indian-sign-language-dictionary
- MediaPipe Hand Landmarker documentation and model setup: https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker

The ISLRTC source confirms that the dictionary is video-based and contains synonyms and some regional variation. This supports using the official dictionary as a reference, but does **not** verify that every proposed grocery label exists or that a specific result is the correct sign for the intended item. Check each sign individually and document reviewer confirmation.
